## What's New in v0.26.1

Beadbox 0.26.1 is the first release since 0.24.1. A 0.26.0 was tagged in August but withdrawn before release; everything it contained is included here.

Available for macOS (Apple Silicon) and Linux (.deb). There is no Windows build in this release, and macOS Intel builds are discontinued.

### Added

- **Workspace rail.** A persistent, resizable rail of project tabs on the left. Click to switch, and the view you were on is preserved — switching from Activity lands on Activity. Works for local `.beads/` projects and server workspaces; rename a project, give it an emoji, or collapse the rail. — Andrei Verdes (#35)
- **Trains tab.** A read-only Trains tab (`Cmd`/`Ctrl`+`4`) shows `.beadtrain` plans beside your beads. Cars are bead IDs; click one to jump to that bead. Beadbox never writes train files — this is a view, not a second tracker. — acrinym (#37)

### Changed

- **Switching projects is instant.** Switching to a project you've already opened this session no longer re-runs the startup check or reloads its beads. — Andrei Verdes (#34)
- **Self-update works.** The app now checks GitHub releases for new versions and updates in place. Earlier builds could not update in-app.

### Fixed

- **Workspace registry durability.** Overlapping edits to your project list (a rename landing next to an icon change) no longer lose one of them; an unreadable registry file is no longer silently emptied; and the one-time registry migration can no longer revert an edit made while it ran. — Andrei Verdes (#33)
- **Pipeline view stays current across workspaces.** A bead edited from the CLI while you were on another workspace now shows in the pipeline view when you switch back, instead of after a 30-second delay.

Thanks to Andrei Verdes and acrinym for their contributions to this release.

Requires the [beads](https://github.com/gastownhall/beads) CLI, version 1.0.1 or newer.
