# What's New in v0.26.0

## Beadbox is now open source

Beadbox has a new home: [github.com/beadbox/beadbox](https://github.com/beadbox/beadbox), MIT-licensed. Read the source, build it yourself, report issues, or send a PR — contributions are welcome, no CLA required.

## Upgrading from an earlier version — one manual step

Earlier versions of Beadbox can't update themselves in-app, so this release needs a one-time download. Get it whichever way you originally installed:

- **Homebrew:** `brew upgrade --cask beadbox` (or fresh: `brew install --cask beadbox/cask/beadbox`)
- **Direct download:** [beadbox.app](https://beadbox.app) or [GitHub Releases](https://github.com/beadbox/beadbox/releases)

Install over your existing copy — your workspaces and settings are kept.

**From this release on, Beadbox keeps itself up to date.** The app now checks for new versions and updates in-app; this is the last manual download.

## Platform availability

- **macOS (Apple Silicon)** and **Linux** (.deb, AppImage) — available now.
- **Windows** — the v0.26 build is coming: it will be added to this same release as soon as code-signing is in place. Watch the [releases page](https://github.com/beadbox/beadbox/releases); until then, Windows users should stay on their current version.
- macOS Intel builds are discontinued. Intel users can build from source (see the README).

## Highlights since v0.24.1

This release rolls up the entire v0.25 development line — it never shipped as a standalone release, so all of it is new here:

- **Faster, lighter app.** The internals were rewritten around a compiled sidecar: smaller download, quicker cold launch.
- **Activity feed.** A timeline of what changed across your workspace — creates, updates, closes, comments — with a live pipeline view of work moving through statuses.
- **One-click workflow advancement.** Move a bead to its next status straight from the detail panel, following your workspace's own status chain.
- **Filters that stick.** Status, type, priority, and assignee filters persist across sessions.
- **Epic tree improvements**, including archiving directly from an epic row.
- **More dependable live updates.** Changes made from the `bd` CLI — by you, scripts, or agents — now appear in the UI within ~2.5 seconds, including cases that previously stalled until an app restart.

## Requirements

Beadbox requires the [beads](https://github.com/gastownhall/beads) CLI, version 1.0.1 or newer (`brew install beads`).
